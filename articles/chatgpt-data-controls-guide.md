ChatGPTを業務で使い始めるとき、まず確認したいのが「会話がモデルの学習に使われるか」です。個人向けプランと法人向けプランでは初期設定が違うため、ここを曖昧にしたまま社内展開すると、入力した顧客情報や社内資料の扱いが人によってバラバラになります。

この記事では、OpenAIのヘルプセンターに書かれている内容をもとに、プラン別の違い・設定手順・社内で決めておくチェックリストをまとめます。数値や制度の話は出てきません。設定と運用の話に絞ります。

## プランで違う「学習への利用」

個人向け（Free / Go / Plus / Pro）では、学習へのデータ利用は初期状態でオンです。設定からオフにできます。

一方、ChatGPT Business / Enterprise / Edu と API では、初期設定で入力・出力が学習に使われません。会社口座で契約し、管理者がメンバーを招待する形にするなら、こちらを前提にした方が説明が楽です。

出典: [ChatGPT のデータ管理](https://help.openai.com/ja-jp/articles/7730893-data-controls-in-chatgpt) / [コンシューマー向けプライバシー](https://openai.com/ja-JP/consumer-privacy/)

## 個人向けで学習をオフにする手順

個人向けプランを当面使う場合でも、最低限次を実施してください。

1. ChatGPTを開き、設定を開く
2. 「データコントロール」を選ぶ
3. 「すべての人のためにモデルを改善する」をオフにする

オフにしたあとの**新しい会話**は学習に使われません。履歴には残ります。履歴を残したまま学習だけ止めたい、という説明はOpenAIのヘルプにもあります。

出典: [履歴をオンのままモデルの学習を無効にする](https://help.openai.com/ja-jp/articles/8983130-what-if-i-want-to-keep-my-history-on-but-disable-model-training)

オフにしたつもりでも、別ブラウザや別アカウントで作業していると設定が効いていません。社内ルールでは「誰が・どのアカウントで・いつ確認したか」を残すと安心です。

## 学習オフでも別途見るべきもの

学習設定をオフにしただけでは足りません。次の3つは別物です。

### 1. 会話履歴

学習に使われなくても、履歴には残ります。不要な会話は削除する。共有リンクを発行した案件は、公開範囲と期限を管理する。データのエクスポートも可能です。退職や端末紛失を想定し、「誰がどの会話を残しているか」を棚卸しできる状態にしておくとよいです。

### 2. メモリ（パーソナライズ）

メモリと学習の設定は別です。メモリを使う場合、過去のやり取りの一部が以降の回答に影響します。顧客名・原価・契約条件など、残したくない情報はそもそも入力しない、またはメモリを使わないルールにするのが現実的です。

### 3. GPTsと外部API

カスタムGPTが外部APIを使う場合、入力の一部が第三者サービスに送られることがあります。社内で使うGPTは、管理者が一覧を把握し、外部連携の有無を確認してから許可する運用が安全です。

出典: [GPTs のデータプライバシー FAQ](https://help.openai.com/ja-jp/articles/8554402-gpts-data-privacy-faq)

## 入力してはいけない情報の例

ツールの設定以前に、「何を貼らないか」を決めておく方が効きます。最低限、次は禁止にすることが多いです。

- 個人情報（氏名・住所・電話・メールの実データ）
- 顧客名・案件の実名（匿名化してから相談する）
- 原価・粗利・値引き率の実数
- 契約書全文、NDA、パスワード、APIキー

見積や提案のたたき台に使う場合も、商談メモは匿名化してから貼る、というルールにすると現場が迷いません。

## 社内で最低限決めるチェックリスト

導入前の打ち合わせで、次を埋めてから使い始めます。

- [ ] 使うプランは個人向けか、Business以上か
- [ ] 個人向けなら「すべての人のためにモデルを改善する」をオフにする担当者と確認日
- [ ] 入力禁止情報の一覧（上記をベースに自社向けに追記）
- [ ] 許可する用途（下書き・要約・チェックリストなど）と禁止する用途
- [ ] GPTsの利用可否、外部API連携の有無の確認方法
- [ ] 共有リンクの発行ルールと削除の担当
- [ ] 退職・異動時の履歴削除・アカウント権限の手順

チェックが埋まっていない状態で「とりあえず個人のPlusで」と進めると、後から説明がつきません。Businessへの切り替え時期も、この表に一行書いておくと判断しやすいです。

## よくある誤解

「学習をオフにしたから、何を貼っても大丈夫」——違います。学習オフはモデル改善への利用を止める設定であり、サービス側での処理や、人間によるサポート対応、外部連携GPTの挙動まで消えるわけではありません。

「Businessなら何も考えなくてよい」——学習の初期設定は安心材料ですが、入力禁止情報とGPT管理は別途必要です。

「メモリを消せば学習も止まる」——メモリと学習は別設定です。両方確認してください。

## まとめ

- 個人向けは学習が初期オン。データコントロールからオフにする
- Business / Enterprise / Edu / API は初期設定で学習に使われない
- 履歴・メモリ・GPTsの外部連携は学習設定とは別管理
- 入力禁止情報と確認担当を決めてから社内展開する
